# 般若心経 データ移行ガイド

## 概要
`hannya-sutra.json` を以下の形式に変換します：
- **旧形式**: `ruby` フィールドが連続文字列
- **新形式**: `rubyMap` フィールドが文字ごとのマッピング配列

## 変換のルール

### 1. 文字単位の対応付け
各漢字（または漢字組）にひらがな読みを1対1対応させます。

```
旧: {"text": "観自在菩薩", "ruby": "かんじざいぼさつ"}
新: {"text": "観自在菩薩", "rubyMap": [
  {"char": "観", "ruby": "かん"},
  {"char": "自", "ruby": "じ"},
  {"char": "在", "ruby": "ざい"},
  {"char": "菩", "ruby": "ぼ"},
  {"char": "薩", "ruby": "さつ"}
]}
```

### 2. 複字読みの扱い
「菩薩」のように2文字で1つの読みになる場合：

```
❌ 間違い:
{"char": "菩", "ruby": "ぼ"},
{"char": "薩", "ruby": "さつ"}

✅ 正しい:
{"char": "菩", "ruby": "ぼ"},
{"char": "薩", "ruby": "さつ"}

※ 各文字に対応する読みを割り当てる
```

### 3. 句読点・特殊文字
読みがない場合は空文字列を使用：

```json
{"char": "、", "ruby": ""}
{"char": "◯", "ruby": ""}
```

### 4. 空白行
スペースのみの行は以下のように保持：

```json
{"char": " ", "ruby": ""}
```

## データソース検証方法

各行のふりがなは以下の公式資料から検証します：
- 公式な般若心経テキスト
- 複数の学問的な注釈本
- 標準的な読み方を参考

**重要**: 複数の資料で異なる読み方がある場合は、最も一般的なものを採用します。

## 問題のある箇所（既知）

### 1. 最初の行
```
旧: "text": "◯仏説般若波羅蜜多心経"
旧: "ruby": "　　　ぶっせつはんにゃはらみたしんぎょう"
```
- `◯` は無読（空文字列）
- 個別文字への分割が必要

### 2. 「三世諸仏」セクション
ふりがなが不正確な可能性があります。
正しい読み：
- 三（さん）
- 世（ぜ）
- 諸（しょ）
- 仏（ぶつ）
